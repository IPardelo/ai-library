# The AI library repository

## What is "The AI Library"?
This project was created to give everyone easy access to free artificial intelligence websites. 100% of this project was created using Google Gemini AI™ following instructions I generated myself. This is my first experience with AI for programming, although I simply compiled the free websites and included them in the project.

## How to use "The AI Library"
Choose the category to filter the tool you need and choose the one that best suits your needs.
